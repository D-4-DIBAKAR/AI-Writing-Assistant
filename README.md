# 📝 AI Writing Assistant

An AI-powered writing assistant that enhances writing with **Grammar Check, Spell Check, and Rephrasing** features. Built using **Node.js, Express, OpenAI, Vite, Tailwind CSS, React Router, and Axios**.

---

## 🚀 Features

✅ **Grammar Check** - Detects and corrects grammatical mistakes in real time.  
✅ **Spell Check** - Identifies and corrects spelling errors.  
✅ **Rephrase Text** - Suggests alternative ways to phrase sentences.  
✅ **Fast & Lightweight** - Powered by OpenAI with a responsive UI.  
✅ **Modern UI** - Styled with Tailwind CSS for a clean experience.  
✅ **Routing** - Seamless navigation using React Router.  
✅ **REST API** - Built with Express.js for efficient processing.

## 🏗️ Installation & Setup

1. **Clone the repository**

```sh
git clone https://github.com/D-4-DIBAKAR/AI-Writing-Assistant.git
cd AI-Writing-Assistant
```

2. **Install dependencies**

   ```sh
   npm install
   ```

3. **Start the backend (Node.js & Express)**

   ```sh
   cd server
   npm run dev
   ```

4. **Start the frontend (React & Vite)**

   ```sh
   cd client
   npm run dev
   ```

5. Open **http://localhost:5173/** in your browser.

## 📌 API Endpoints

| Method | Endpoint             | Description                            |
| ------ | -------------------- | -------------------------------------- |
| POST   | `/api/grammar-check` | Checks grammar in text                 |
| POST   | `/api/spell-check`   | Detects & corrects spelling errors     |
| POST   | `/api/rephrase`      | Rewrites text with better alternatives |
